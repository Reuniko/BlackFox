Engine

Class BlackFox\Engine handles the tasks of managing the connection of the necessary entities, generating content, and generating the wrapper for content. All requests for php files and folders should be redirected to the file /index.php, which launches the engine.

The engine works in two stages:

Constructor

  • Loads configuration
  • Initializes a session
  • Registers the method for autoloading classes
  • Registers the method for handling uncaught exceptions
  • Loads the BlackFox core
  • Initializes the global instance of the database connection
  • Initializes the global instance of the cache

Method Work

  • Loads information about the requested section
  • Initializes the global instance of the current user
  • Checks access to the section
  • Generates page content (or content that displays an error that occurred while generating the page content)
  • If required, generates the page wrapper and wraps the content in it

Content generation

The content of the requested page is generated by a pair of methods, ShowContent and MakeContent.
The ShowContent method calls the method MakeContent and handles all exceptions coming from it, acting as an error-free wrapper method that displays content in any case, even if an error occurs.
The MakeContent method sequentially tries to generate content for the requested page:

  1. Looks for the requested file, or the index.php file in the requested folder
  2. Looks for the .router.php file up the directory hierarchy (going through all virtual roots)
  3. Searches for a redirect or a content page in the database

On failure, it throws ExceptionPageNotFound, which is handled by the method ShowContent.

For more information, see Virtual root.

Useful properties and methods of the engine

Since the engine is a common repository for all dynamically generated data, it is an exception to the rule of disallowing modification of a global instance's internal state.

Access to the properties and methods listed below is done:

  • in the context of a page — via $this->
  • in the context of a unit — via $this->ENGINE->
  • in other contexts — via \BlackFox\Engine::I()->

Own engine

In order to override the behavior of engine methods, you must:

  • inherit it into your own core and namespace
  • set the key 'BlackFox\Engine' in the configuration, in the 'overrides' section
  • include it in the file /includes.php (required, because the engine can't find itself before being loaded)
  • launch it in the file /index.php (optional)
/Site/classes/Engine.php namespace Site; class Engine extends \BlackFox\Engine { public function Show403() { require($_SERVER['DOCUMENT_ROOT'] . $this->TEMPLATE_PATH . '/403.php'); } public function Show404() { require($_SERVER['DOCUMENT_ROOT'] . $this->TEMPLATE_PATH . '/404.php'); } public function ShowAuthForm($message = null) { UnitLogin::Run([ 'LINK_SUCCESS' => '/profile/', 'LINK_FORGOT' => '/auth/forgot.php', 'LINK_REGISTER' => '/auth/registration.php', 'MESSAGE' => $message, ]); } }
/config.php return [ // ... 'overrides' => [ 'BlackFox\Engine' => 'Site\Engine', // ... ], // ... ]; /includes.php require_once('Site/classes/Engine.php'); // ... /index.php require_once("BlackFox/includes.php"); \Site\Engine::I()->Work();
