Cache

Class BlackFox\Cache is an interface that defines how caching works.
It doesn't do anything on its own, so it should be overridden in the config with one of the drivers:

  • BlackFox\CacheRedis
  • ... your own driver :)

Methods

Name Params Description Exception
Get string|array $key Retrieves value(s) by key(s), preserving type Value not found
Put string $key, $value,
int $ttl = null, array $tags = [] 		Saves the value under the specified key A value already exists under the specified key
Set Overwrites the value under the specified key, even if it already exists
Delete string $key Deletes the value at a key, if one exists
Strike string|array $tags Removes all keys and values associated with the specified tags
Clear Clears the cache

Examples

try { $elements = \BlackFox\Cache::I()->Get('elements'); } catch (\BlackFox\ExceptionCache $error) { $elements = \Example\Elements::I()->Select(); \BlackFox\Cache::I()->Set('elements', $elements); } return $elements;
