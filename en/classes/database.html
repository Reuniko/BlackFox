Database

Abstract class BlackFox\Database is an interface that describes access to a relational database.
This class must be overridden in the configuration with one of its descendants:

  • BlackFox\MySQL
  • BlackFox\Postgres
  • ... or write your own driver :)

Methods

Title Options Description
Query$SQL, $key = nullMust execute any SQL query and return the result as a two-dimensional array if it was a SELECT query
QuerySingleInsert$SQL, $increment = nullMust execute an INSERT query and return the last value of the specified column (usually the identifier)
Escape$dataEscapes special characters in a string for use in an SQL statement
Quote$dataWraps the string in the quotation marks used by the current database to denote string constants
RandomReturns a string describing the SQL random number function
StartTransactionStarts a transaction
RollbackRolls back a transaction
CommitCommits a transaction
CompileSQLSelectarray $partsGlues an array of parts of an SQL SELECT query into a string
Truncate$tableRemoves all data from the table and resets its internal counter
Drop$tableDeletes a table

Access to the global instance

  • In the engine and SCRUD contexts: $this->Database->
  • In other contexts: \BlackFox\Database::I()->
$DB = \BlackFox\Database::I(); $users = $DB->Query("SELECT * FROM system_users");
