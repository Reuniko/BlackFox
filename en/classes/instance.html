Instance

Trait BlackFox\Instance adds static methods ::N() and ::I() to a class, performing factory tasks of creating local or global instances of this class.

Dependency Inversion

Often you need to create a class and its instance (the dependent), which depends on another class or interface (the dependency).
For example, the class Users uses public methods of the class MySQL:

class Users { public function GetByID(int $ID) { global $MySQL; return $MySQL->Query("SELECT * FROM users WHERE ID='{$ID}'"); } }

In this implementation, the class Users becomes impossible to reuse in conjunction with another database. More generally: a dependent class loses its flexibility regarding the dependency. To solve this problem, the Dependency Inversion principle is used, the implementation of which is as follows:

  • pass the dependency to the constructor of the dependent class as a strongly typed parameter (the type can be a specific class, abstract class or interface)
  • save a link to the dependency in a property of the dependent class
  • use this link to access dependency methods strictly within the contract described by the dependency
class Users { /**@var Database $Database */ private $Database; public function __construct(Database $Database) { $this->Database = $Database; } public function GetByID(int $ID) { return $this->Database->Query("SELECT * FROM users WHERE ID='{$ID}'"); } }

Now the class Users can be used in conjunction with many different databases, as long as they abide by the contract described by the class or interface Database.
But in such an implementation, it is not very convenient to instantiate new instances of the dependent class:

$Database = new Database(); $Users = new Users($Database);

To simplify the creation of new instances of dependent classes, you can add the trait Instance to your class:

class Users { use \BlackFox\Instance; // ... }

Then two static methods ::N() and ::I() will appear in the dependent class, which will automatically substitute global instances of the required dependencies into the constructor parameters:

// make new local instance $Users = Users::N(); $data = $Users->GetByID(1); // get (or make and get) global instance $data = Users::I()->GetByID(1);

This retains the ability to locally redefine some or all of the dependencies:

// make another local instance connected to another database $AnotherUsers = Users::N(['Database' => AnotherDatabase::I()]); $data = $AnotherUsers->GetByID(1);

::N() — creating a new instance

The static method ::N() takes a one-dimensional dictionary of constructor parameters as input and returns a new instance of the appropriate class.

class User { use \BlackFox\Instance; public function __construct(Database $Database, int $ID, bool $optional_flag = true) { $this->Database = $Database; $this->ID = $ID; $this->optional_flag = $optional_flag; } } $User1 = User::N(['ID' => 1]); // ok $User2 = User::N(['ID' => 2, 'optional_flag' => false]); // ok $User3 = User::N(['ID' => 3, 'Database' => AnotherDatabase::I()]); // ok $User4 = User::N([]); // error: ID is missing

::I() — return (or create and return) a global instance

Often a project requires one universal global object (instance), accessible from any part of the code.
The static method ::I() accepts, once, a one-dimensional dictionary of constructor parameters, creates a global instance of the appropriate class (if one hasn't already been created), and returns a link to it.
Calling ::I() with a parameter again will throw an error, since a global instance already exists.
Calling ::I() without parameters returns a link to the existing global instance.

class Database { use \BlackFox\Instance; public function __construct(array $params) {} public function Query($SQL) {} } Database::I(['params' => $params]); // ok Database::I()->Query($SQL1); // ok Database::I()->Query($SQL2); // ok Database::I(['params' => $params]); // error

Dictionary of parameters

The one-dimensional dictionary of constructor parameters is optional and is processed as follows:

  • If a value for the parameter is passed, use it
  • If the parameter value is missing:
    • If the parameter is optional, substitute its default value
    • If the parameter is required:
      • If the parameter has no type, or its type is a built-in one, throw an error
      • If the parameter type is not built-in (a specific class, abstract class, or interface):
        • If it's possible to map the type to a global instance, substitute a link to that global instance
        • Otherwise, throw an error

Mapping a parameter's type to a global instance works as follows:

  • If there is a key in the global override configuration describing this type, use the corresponding global instance
  • Otherwise, if the type is a specific class using the Instance trait, use its own global instance
  • Otherwise, throw an error, since it cannot find a suitable global instance

Global override rules

The current class is considered "appropriate" unless otherwise specified in the global override rules configuration.
The global override rules are a dictionary described under the 'overrides' key of the configuration array:

  • key — string, identifier of a specific class, abstract class, or interface which should be overridden
  • value — string, identifier of the specific class to override with
return [ // ... 'overrides' => [ 'BlackFox\Engine' => 'Example\Engine', 'BlackFox\Database' => 'BlackFox\MySQL', 'BlackFox\Captcha' => 'BlackFox\CaptchaGoogleRecaptchaV2', 'BlackFox\Users' => 'Example\Users', 'BlackFox\Cache' => 'BlackFox\CacheRedis', ], // ... ]; BlackFox\Engine::I(); // <-- Example\Engine BlackFox\Database::I(); // <-- BlackFox\MySQL BlackFox\Captcha::I(); // <-- BlackFox\CaptchaGoogleRecaptchaV2 BlackFox\Users::I(); // <-- Example\Users BlackFox\Cache::I(); // <-- BlackFox\CacheRedis

It's worth noting that these rules are used only by the Instance trait methods, so it remains possible to create any objects locally using the new keyword.

Method AddOverrides

The global static method ::AddOverrides(array $overrides) allows you to add or replace override rules dynamically.

// AddOverrides is a static trait method - call it through any class using \BlackFox\Instance \BlackFox\Engine::AddOverrides([ 'BlackFox\Cache' => 'BlackFox\CacheRedis', ]);
