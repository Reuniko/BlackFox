Methods

Along with all the methods provided by SCRUD, the class has additional methods:

Name Parameters Description
SetPassword$ID, $passwordSets a new password
CheckPassword$ID, $passwordVerifies a password
AddGroup$ID, $groupAdds the user to a group
GetRecoveryString$IDGenerates and returns a new string for password recovery (HASH)
