User

Class BlackFox\User is designed to work with the current user's session.
In the engine context, it's accessible via $this->User->; in the unit context, via $this->USER-> (note the different case); in other contexts — via \BlackFox\User::I()->

Properties

Name Type Description
$IDnumberuser ID

$user_id = \BlackFox\User::I()->ID; $user_login = \BlackFox\User::I()->FIELDS['LOGIN']; $is_authorized = \BlackFox\User::I()->IsAuthorized(); $is_root = \BlackFox\User::I()->InGroup('root');
