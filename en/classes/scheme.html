Scheme

Class BlackFox\Scheme accepts a list of SCRUD descendants in its constructor and provides methods to synchronize the structure of the database.

Basic methods

Method Params Description Return
__construct SCRUD[...]|string[...] $Tables You can pass a mixed array of objects and strings (names of SCRUD descendant classes) to the constructor.
Compare Compares the structure of the database (tables, columns, keys, indexes, constraints) with the structure described in the SCRUD descendant classes. A multidimensional array describing possible changes to the database structure needed to convert it to the structure described in the SCRUD descendant classes:
  • MESSAGE — description of the change
  • TABLE — code of the modified table, or the index or constraint associated with it
  • SQL — SQL to make the change
  • ... — other data depending on the change
Synchronize Synchronizes the database structure if it differs from the structure described in the SCRUD descendant classes.

Usage

Usually, you don't need to run the methods above manually — instead you:

  • create and return an instance of the Scheme class in the GetScheme method of your core
  • run the schema sync from the Upgrade method of your core
  • then, either:
    • run a full engine upgrade: the file /BlackFox/upgrade.php
    • or use the SchemeSynchronizer unit in the admin area, at /admin/BlackFox/SchemeSynchronizer.php
namespace Testing; class Core extends \BlackFox\ACore { // ... public function GetScheme() { return new \BlackFox\Scheme([ Grades::I(), Rooms::I(), Timetable::I(), Students::I(), ]); } public function Upgrade() { $this->GetScheme()->Synchronize(); } // ... }
