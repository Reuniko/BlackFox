Adminer

Unit BlackFox\Adminer accepts a SCRUD descendant object as a parameter and provides full control over the table:

  • A table view with filtering, sorting, page navigation, and the ability to change the display order of columns and filters.
  • Forms for creating and updating elements
  • The ability to delete elements, individually or in groups
\BlackFox\Adminer::Run(['SCRUD' => Docs\Feedback::I()]);

Example: adding a view

Suppose you want to add an extra tab to the edit form of an element, to hold the form for a new action.
To do this, create a descendant unit of Adminer, and:

Override GetTabsOfUpdate:

namespace BlackFox; class AdminerUsers extends Adminer { // ... public function GetTabsOfUpdate() { return parent::GetTabsOfUpdate() + [ 'actions' => [ 'NAME' => T([ 'en' => 'Actions', 'ru' => 'Действия', ]), 'VIEW' => 'element_tab_actions', ], ]; } }

Create the view element_tab_actions:

/** @var \BlackFox\Adminer $this */ /** @var array $RESULT */ ?> <form method="post"> <button type="submit" name="ACTION" value="Login" class="btn btn-info" > <?= T([ 'en' => 'Log in with this user', 'ru' => 'Авторизоваться под этим пользователем', ]) ?> </button> </form>

Example: view inheritance

Suppose you want to rewrite the create form of an element.
To do this, create a descendant unit of Adminer, and override the element view:

<?php /** @var \BlackFox\Adminer $this */ ?> <?php /** @var array $RESULT */ ?> <? if ($RESULT['MODE'] <> 'Create'): ?> <? require $this->GetParentView(); ?> <? else: ?> <form method="post" enctype="multipart/form-data"> <!-- new form for create --> </form> <? endif; ?>

The method GetParentView() connects the original view.
