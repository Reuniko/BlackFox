Adminer

Юнит BlackFox\Adminer принимает на вход как параметр объект-наследник от SCRUD и предоставляет полный контроль над таблицей:

  • Просмотр в виде таблицы с возможностями фильтрации, сортировки, постраничного просмотра, а также персональных настроек порядка и отображения столбцов таблицы и фильтра
  • Формы для создания и редактирования элементов
  • Возможность удалять как отдельные элементы, так и элементы группами
\BlackFox\Adminer::Run(['SCRUD' => Docs\Feedback::I()]);

Пример добавления отображения

Допустим, необходимо добавить дополнительную вкладку в форму редактирования элемента, на которой расположить форму для нового действия.
Для этого следует создать юнит-наследник от Adminer, а также:

Дополнить метод GetTabsOfUpdate:

namespace BlackFox; class AdminerUsers extends Adminer { // ... public function GetTabsOfUpdate() { return parent::GetTabsOfUpdate() + [ 'actions' => [ 'NAME' => T([ 'en' => 'Actions', 'ru' => 'Действия', ]), 'VIEW' => 'element_tab_actions', ], ]; } }

Создать отображение element_tab_actions:

/** @var \BlackFox\Adminer $this */ /** @var array $RESULT */ ?> <form method="post"> <button type="submit" name="ACTION" value="Login" class="btn btn-info" > <?= T([ 'en' => 'Log in with this user', 'ru' => 'Авторизоваться под этим пользователем', ]) ?> </button> </form>

Пример наследования отображения

Допустим, необходимо переписать форму создания элемента.
Для этого следует создать юнит-наследник от Adminer, а также переопределить отображение element:

<?php /** @var \BlackFox\Adminer $this */ ?> <?php /** @var array $RESULT */ ?> <? if ($RESULT['MODE'] <> 'Create'): ?> <? require $this->GetParentView(); ?> <? else: ?> <form method="post" enctype="multipart/form-data"> <!-- new form for create --> </form> <? endif; ?>

Метод GetParentView() подключит оригинальное отображение.
