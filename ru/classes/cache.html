Cache

Класс BlackFox\Cache является интерфейсом, определяющим работу с кешем.
Сам по себе он не работает, поэтому его следует переопределить в конфиге на один из драйверов:

  • BlackFox\CacheRedis
  • ... ваш драйвер

Методы

Название Параметры Описание Исключение
Get string|array $key Извлекает значение/значения по ключу/ключам, сохраняя тип Значение не найдено
Put string $key, $value,
int $ttl = null, array $tags = [] 		Сохраняет значение в указанный ключ Значение в указанном ключе уже существует
Set Перезаписывает значение в указанный ключ, даже если оно уже существует
Delete string $key Удаляет значение по ключу, если оно существует
Strike string|array $tags Удаляет все ключи и значения, связанные с указанными тегами
Clear Очищает кеш

Примеры

try { $elements = \BlackFox\Cache::I()->Get('elements'); } catch (\BlackFox\ExceptionCache $error) { $elements = \Example\Elements::I()->Select(); \BlackFox\Cache::I()->Set('elements', $elements); } return $elements;
