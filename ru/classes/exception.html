Exception

Класс BlackFox\Exception является прямым потомком \Exception, в конструкторе принимает на вход не только строку, но и массив строк. Это позволяет группировать исключения:

$errors = []; if (empty($user['LOGIN'])) $errors[] = "Specify login"; if (empty($user['EMAIL'])) $errors[] = "Specify email"; if (empty($user['PASSWORD'])) $errors[] = "Specify password"; if ($errors) throw new \BlackFox\Exception($errors);

В дальнейшем это исключение может быть отловлено и обработано как \Exception, в этом случае метод getMessage() склеит массив в строку. Рекомендуется отлавливать такие исключения как \BlackFox\Exception и использовать метод getArray() для доступа к массиву строк исключения.

try { // call with possibility of exception } catch (\BlackFox\Exception $Exception) { $errors = $Exception->getArray(); \BlackFox\Engine::I()->ShowErrors($errors); } catch (\Exception $Exception) { $error = $Exception->getMessage(); \BlackFox\Engine::I()->ShowErrors([$error]); }

Классы-наследники

Перечисленные ниже классы-наследники не обладают каким-либо дополнительным внутренним функционалом. Некоторые из них обрабатываются движком особым образом.

  • ExceptionAccessDenied — заставляет движок отобразить страницу авторизации, если пользователь не авторизован
  • ExceptionAuthRequired — заставляет движок отобразить страницу авторизации
  • ExceptionCache
  • ExceptionCaptcha
  • ExceptionElementNotFound — заставляет движок отобразить страницу 404
  • ExceptionNotAllowed
  • ExceptionNotImplemented
  • ExceptionPageNotFound — заставляет движок отобразить страницу 404
  • ExceptionSQL
  • ExceptionType

Собственное исключение

Для того чтобы использовать это исключение в своём модуле, у вас есть выбор:

  • Каждый раз указывать полный путь к исключению: throw new \BlackFox\Exception([...]);
  • Указать use в начале файла: use \BlackFox\Exception;
  • Создать пустой класс-наследник Exception, поместив его в неймспейс модуля (рекомендуется):
namespace Example; class Exception extends \BlackFox\Exception {}
