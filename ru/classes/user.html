User

Класс BlackFox\User предназначен для работы с сессией текущего пользователя.
В контексте движка он доступен через $this->User->; в контексте юнита — через $this->USER-> (обратите внимание на регистр); в иных контекстах — через \BlackFox\User::I()->

Свойства

Название Тип Описание
$IDчислоИдентификатор пользователя
$FIELDSмассивСловарь полей пользователя
$GROUPSмассивСписок групп пользователя
$user_id = \BlackFox\User::I()->ID; $user_login = \BlackFox\User::I()->FIELDS['LOGIN']; $is_authorized = \BlackFox\User::I()->IsAuthorized(); $is_root = \BlackFox\User::I()->InGroup('root');

Методы

Название Параметры Описание
Init $ID Загружает данные пользователя, вызывается из конструктора
Authorization $login, $password Пытается авторизовать пользователя по указанным реквизитам
Login $ID Авторизует пользователя с указанным идентификатором
Logout Деавторизует пользователя
IsAuthorized Возвращает true, если пользователь авторизован
InGroup $group Возвращает true, если пользователь принадлежит указанной группе
InAnyOfGroups $groups Возвращает true, если пользователь принадлежит хотя бы одной из указанных групп
