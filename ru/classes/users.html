Users

Класс BlackFox\Users является наследником SCRUD, описывает таблицу пользователей.

Поля

Код Тип Имя Описание
ID*NUMBERID
LOGIN*STRINGЛогин
PASSWORD*PASSWORDПарольВ базе хранится sha1 хеш пароля
SALT*STRINGСоль
HASHSTRINGХэшДля восстановления пароля
LANGUAGESTRINGЯзык
LAST_AUTHDATETIMEПоследнее время авторизации
REGISTER_MOMENTDATETIMEВремя регистрации
FIRST_NAMESTRINGИмя
LAST_NAMESTRINGФамилия
MIDDLE_NAMESTRINGОтчество
EMAILSTRINGЭлектропочта

$Users = \BlackFox\Users::I(); $user = $Users->Read(['LOGIN' => 'Root']); if (empty($user)) throw new \BlackFox\ExceptionElementNotFound(); $Users->Update($user['ID'], [ 'FIRST_NAME' => 'Root', 'EMAIL' => 'email@email.com', ]); $Users->AddGroup($user['ID'], 'root'); $Users->SetPassword($user['ID'], '123456'); if (!$Users->CheckPassword($user['ID'], '123456')) throw new \BlackFox\ExceptionAccessDenied(); $recovery_string = $Users->GetRecoveryString($user['ID']);

Методы

Наряду со всеми методами, которые предоставляет SCRUD, класс обладает дополнительными методами:

Название Параметры Описание
SetPassword$ID, $passwordУстанавливает новый пароль
CheckPassword$ID, $passwordПроверяет пароль
AddGroup$ID, $groupДобавляет пользователя в группу
GetRecoveryString$IDГенерирует и возвращает новую строку для восстановления пароля (HASH)

Переопределение класса

Если описанный выше набор полей и методов вас не устраивает, вам следует создать класс-наследник от BlackFox\Users, добавить/модифицировать/удалить поля/методы, и переопределить класс в конфигурации.

namespace Example; class Users extends \BlackFox\Users { public function Init() { parent::Init(); // сперва заполняет $this->fields базовым набором unset($this->fields['AVATAR']); $this->fields += [ 'VK_ID' => [ 'TYPE' => 'NUMBER', 'NAME' => 'Vk identifier', ], ]; } }
/config.php return [ // ... 'overrides' => [ // ... 'BlackFox\Users' => 'Example\Users', ], ];
