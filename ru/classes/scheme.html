Scheme

Класс BlackFox\Scheme принимает на вход в конструктор массив-список наследников SCRUD и предоставляет методы для синхронизации структуры базы данных.

Основные методы

Метод Параметры Описание Возврат
__construct SCRUD[...]|string[...] $Tables В конструктор можно передать смешанный массив из объектов и строк (названия классов-наследников от SCRUD).
Compare Сравнивает структуру базы данных (таблицы, колонки, ключи, индексы, ограничения) со структурой, описанной в классах-наследниках от SCRUD. Многомерный массив, описывающий возможные изменения структуры базы данных для приведения её к структуре, описанной в классах-наследниках от SCRUD:
  • MESSAGE — описание изменения
  • TABLE — код изменяемой таблицы или связанного с ней индекса или ограничения
  • SQL — SQL-код для изменения структуры
  • ... — прочие данные в зависимости от изменения
Synchronize Синхронизирует структуру базы данных, если она отличается от структуры, описанной в классах-наследниках SCRUD.

Использование

Обычно вам не требуется запускать описанные выше методы вручную, вместо этого вы:

  • создаёте и возвращаете экземпляр класса Scheme в методе GetScheme вашего ядра
  • в методе Upgrade вашего ядра запускаете синхронизацию схемы
  • на выбор:
    • запускаете полный апгрейд движка: файл /BlackFox/upgrade.php
    • используете юнит SchemeSynchronizer в административной части: адрес /admin/BlackFox/SchemeSynchronizer.php
namespace Testing; class Core extends \BlackFox\ACore { // ... public function GetScheme() { return new \BlackFox\Scheme([ Grades::I(), Rooms::I(), Timetable::I(), Students::I(), ]); } public function Upgrade() { $this->GetScheme()->Synchronize(); } // ... }
