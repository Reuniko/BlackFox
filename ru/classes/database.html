Database

Абстрактный класс BlackFox\Database является интерфейсом, описывающим доступ к реляционной базе данных.
Этот класс должен быть переопределён в конфигурации на одного из своих наследников:

  • BlackFox\MySQL
  • BlackFox\Postgres
  • ... или напишите собственный драйвер :)

Методы

Название Параметры Описание
Query$SQL, $key = nullДолжен выполнить любой SQL-запрос и вернуть результат в виде двухмерного массива, если это был SQL-запрос SELECT
QuerySingleInsert$SQL, $increment = nullДолжен выполнить SQL-запрос INSERT и вернуть последнее значение указанной колонки (обычно идентификатора)
Escape$dataЭкранирует специальные символы в строке для использования в SQL-выражении
Quote$dataОборачивает строку в кавычки, используемые текущей базой данных для обозначения строковых констант
RandomВозвращает строку, описывающую SQL-функцию случайного числа
StartTransactionНачинает транзакцию
RollbackОтменяет транзакцию
CommitЗакрепляет транзакцию
CompileSQLSelectarray $partsСклеивает массив частей SQL-запроса SELECT в строку
Truncate$tableУдаляет все данные из таблицы и сбрасывает её внутренний счётчик
Drop$tableУдаляет таблицу

Доступ к глобальному инстансу

  • В контекстах движка и SCRUD: $this->Database->
  • В иных контекстах: \BlackFox\Database::I()->
$DB = \BlackFox\Database::I(); $users = $DB->Query("SELECT * FROM system_users");
