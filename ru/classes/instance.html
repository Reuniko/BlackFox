Instance

Трейт BlackFox\Instance добавляет в класс статические методы ::N() и ::I(), выполняющие фабричные задачи создания локальных или глобальных экземпляров (инстансов) данного класса.

Инверсия зависимостей

Часто нужно создать класс и его экземпляр (далее — зависимый), который зависит от другого класса или интерфейса (далее — зависимость).
Например, класс Users использует публичные методы класса MySQL:

class Users { public function GetByID(int $ID) { global $MySQL; return $MySQL->Query("SELECT * FROM users WHERE ID='{$ID}'"); } }

В подобной реализации класс Users становится невозможно повторно использовать в связке с другой базой данных. В более общих чертах: зависимый класс теряет свою гибкость относительно зависимости. Для разрешения этой проблемы используют принцип инверсии зависимостей, реализация которого заключается в следующем:

  • передать зависимость в конструктор зависимого класса в виде строго типизированного параметра (тип может быть конкретным классом, абстрактным классом или интерфейсом)
  • сохранить ссылку на зависимость в свойстве зависимого класса
  • использовать эту ссылку для доступа к методам зависимости строго в рамках контракта, описанного зависимостью
class Users { /**@var Database $Database */ private $Database; public function __construct(Database $Database) { $this->Database = $Database; } public function GetByID(int $ID) { return $this->Database->Query("SELECT * FROM users WHERE ID='{$ID}'"); } }

Теперь класс Users можно использовать в связке со множеством разных баз данных, соблюдающих контракт, описанный в классе или интерфейсе Database.
Но в подобной реализации не очень удобно инстанциировать новые экземпляры зависимого класса:

$Database = new Database(); $Users = new Users($Database);

Для упрощения создания новых экземпляров зависимых классов вы можете добавить в свой класс трейт Instance:

class Users { use \BlackFox\Instance; // ... }

После чего в зависимом классе появятся два статических метода ::N() и ::I(), которые будут автоматически подставлять в параметры конструктора глобальные инстансы требуемых зависимостей:

// make new local instance $Users = Users::N(); $data = $Users->GetByID(1); // get (or make and get) global instance $data = Users::I()->GetByID(1);

При этом сохранится возможность локально переопределять некоторые или все зависимости:

// make another local instance connected to another database $AnotherUsers = Users::N(['Database' => AnotherDatabase::I()]); $data = $AnotherUsers->GetByID(1);

::N() — создание нового экземпляра

Статический метод ::N() принимает на вход одномерный словарь параметров конструктора и возвращает новый экземпляр подходящего класса.

class User { use \BlackFox\Instance; public function __construct(Database $Database, int $ID, bool $optional_flag = true) { $this->Database = $Database; $this->ID = $ID; $this->optional_flag = $optional_flag; } } $User1 = User::N(['ID' => 1]); // ok $User2 = User::N(['ID' => 2, 'optional_flag' => false]); // ok $User3 = User::N(['ID' => 3, 'Database' => AnotherDatabase::I()]); // ok $User4 = User::N([]); // error: ID is missing

::I() — возврат (или создание+возврат) глобального экземпляра

Зачастую в проекте требуется один универсальный глобальный объект (инстанс), доступ к которому возможен из любой части кода.
Статический метод ::I() однократно принимает на вход одномерный словарь параметров конструктора, создаёт глобальный инстанс подходящего класса (если тот ещё не создан) и возвращает ссылку на него.
Повторный вызов метода ::I() с параметром кинет ошибку, поскольку глобальный инстанс уже создан.
Повторный вызов метода ::I() без параметров вернёт ссылку на глобальный инстанс.

class Database { use \BlackFox\Instance; public function __construct(array $params) {} public function Query($SQL) {} } Database::I(['params' => $params]); // ok Database::I()->Query($SQL1); // ok Database::I()->Query($SQL2); // ok Database::I(['params' => $params]); // error

Словарь параметров

Одномерный словарь параметров конструктора является опциональным и обрабатывается следующим образом:

  • Если значение параметра передано — подставляет его
  • Если значение параметра отсутствует:
    • Если параметр опциональный — подставляет значение по умолчанию
    • Если параметр обязательный:
      • Если у параметра тип отсутствует или является базовым — кидает ошибку
      • Если тип параметра является пользовательским (конкретный класс, абстрактный класс или интерфейс):
        • Если возможно сопоставить пользовательский тип с глобальным инстансом — подставляет ссылку на глобальный инстанс в качестве передаваемого значения
        • В противном случае — кидает ошибку

Сопоставление пользовательского типа с глобальным инстансом происходит следующим образом:

  • Если в конфигурации глобального переопределения зависимостей есть ключ, описывающий связь пользовательского типа с глобальным инстансом — использует его
  • Иначе, если пользовательский тип является конкретным классом с трейтом Instance — использует его собственный глобальный инстанс
  • В противном случае кидает ошибку, поскольку не может найти подходящий глобальный инстанс

Глобальные правила переопределений

Подходящим считается текущий класс, если не указано иного в конфигурации правил глобальных переопределений.
Конфигурация правил глобальных переопределений — это словарь, описанный в ключе 'overrides' массива конфигурации:

  • ключ — строка, идентификатор конкретного класса, абстрактного класса или интерфейса, который следует переопределять
  • значение — строка, идентификатор конкретного класса, которым следует переопределять
return [ // ... 'overrides' => [ 'BlackFox\Engine' => 'Example\Engine', 'BlackFox\Database' => 'BlackFox\MySQL', 'BlackFox\Captcha' => 'BlackFox\CaptchaGoogleRecaptchaV2', 'BlackFox\Users' => 'Example\Users', 'BlackFox\Cache' => 'BlackFox\CacheRedis', ], // ... ]; BlackFox\Engine::I(); // <-- Example\Engine BlackFox\Database::I(); // <-- BlackFox\MySQL BlackFox\Captcha::I(); // <-- BlackFox\CaptchaGoogleRecaptchaV2 BlackFox\Users::I(); // <-- Example\Users BlackFox\Cache::I(); // <-- BlackFox\CacheRedis

Стоит отметить, что эти правила используются только методами трейта Instance, а значит остаётся возможность создавать локально любые объекты, используя ключевое слово new.

Метод AddOverrides

Глобальный статический метод ::AddOverrides(array $overrides) позволяет динамично добавить или заменить правила переопределений.

// AddOverrides - это статический метод трейта, вызывается через любой класс с \BlackFox\Instance \BlackFox\Engine::AddOverrides([ 'BlackFox\Cache' => 'BlackFox\CacheRedis', ]);
