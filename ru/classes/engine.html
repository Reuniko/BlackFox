Engine

Класс BlackFox\Engine выполняет задачи менеджмента подключения необходимых сущностей, генерации контента и генерации обёртки для контента. Все запросы на php-файлы и папки должны быть перенаправлены в файл /index.php, который запускает движок.

Работа движка происходит в два этапа:

Конструктор

  • Загружает конфигурацию
  • Инициализирует сессию
  • Регистрирует метод автозагрузки классов
  • Регистрирует метод обработки упущенных исключений
  • Загружает ядро BlackFox
  • Инициализирует глобальный инстанс подключения к базе данных
  • Инициализирует глобальный инстанс подключения к кешу

Метод Work

  • Загружает информацию о запрашиваемой секции
  • Инициализирует глобальный инстанс текущего пользователя
  • Проверяет наличие доступа к секции
  • Генерирует контент страницы (или контент, отображающий ошибку, произошедшую в процессе генерации контента страницы)
  • Если требуется, генерирует обёртку страницы и оборачивает контент в неё

Генерация контента

Генерация контента запрошенной страницы происходит в паре методов ShowContent и MakeContent.
Метод ShowContent вызывает метод MakeContent и обрабатывает все пришедшие из него исключения, являясь таким образом безошибочным методом-обёрткой, отображающим контент в любом случае, даже если произошла ошибка.
Метод MakeContent последовательно пытается сгенерировать контент для запрошенной страницы:

  1. Ищет запрошенный файл или файл index.php в запрошенной папке
  2. Ищет файл .router.php вверх по иерархии директорий (перебирая все виртуальные корни)
  3. Ищет редирект или контентную страницу в базе данных

В случае неуспеха бросает исключение ExceptionPageNotFound, которое обрабатывается методом ShowContent.

Дополнительная информация доступна в разделе Виртуальный корень.

Полезные свойства и методы движка

Поскольку движок является общим хранилищем всех динамически генерируемых данных, на него распространяется исключение в плане разрешения модификации внутреннего состояния глобального инстанса.

Доступ к нижеперечисленным свойствам и методам движка осуществляется:

  • в контексте страницы — через $this->
  • в контексте юнита — через $this->ENGINE->
  • в иных контекстах — через \BlackFox\Engine::I()->

Собственный движок

Для того чтобы дополнять или переопределять поведение методов движка, нужно:

  • отнаследовать его в своё ядро и неймспейс
  • переопределить ключ 'BlackFox\Engine' в конфигурации, в разделе 'overrides'
  • подключить в файле /includes.php (необходимо, поскольку движок не может найти сам себя, предварительно не загрузившись)
  • запустить в файле /index.php (опционально)
/Site/classes/Engine.php namespace Site; class Engine extends \BlackFox\Engine { public function Show403() { require($_SERVER['DOCUMENT_ROOT'] . $this->TEMPLATE_PATH . '/403.php'); } public function Show404() { require($_SERVER['DOCUMENT_ROOT'] . $this->TEMPLATE_PATH . '/404.php'); } public function ShowAuthForm($message = null) { UnitLogin::Run([ 'LINK_SUCCESS' => '/profile/', 'LINK_FORGOT' => '/auth/forgot.php', 'LINK_REGISTER' => '/auth/registration.php', 'MESSAGE' => $message, ]); } }
/config.php return [ // ... 'overrides' => [ 'BlackFox\Engine' => 'Site\Engine', // ... ], // ... ]; /includes.php require_once('Site/classes/Engine.php'); // ... /index.php require_once("BlackFox/includes.php"); \Site\Engine::I()->Work();
