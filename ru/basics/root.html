Виртуальный корень

По умолчанию все запросы от пользователей на исполняемый файл (*.php) или папку обрабатываются фреймворком (класс Engine) следующим образом: для каждого указанного ниже файла, для каждого виртуального корня от первого к последнему идёт поиск указанных файлов:

  1. непосредственно запрошенный php-файл или файл index.php в запрошенной папке
  2. файл .router.php вверх по иерархии директорий относительно запроса

Как только первый файл найден — исполняет его, прерывая дальнейший поиск.
Все активные виртуальные корни должны быть зарегистрированы в конфиге (ключ 'roots').

Например

Допустим, что у нас есть два виртуальных корня /Site/root и /BlackFox/root:

Запрос Поиск подключаемой сущности
/feedback.php
  • /Site/root/feedback.php
  • /BlackFox/root/feedback.php
  • /Site/root/.router.php
  • /BlackFox/root/.router.php
    		•
    /admin/
  • /Site/root/admin/index.php
  • /BlackFox/root/admin/index.php
  • /Site/root/admin/.router.php
  • /BlackFox/root/admin/.router.php
  • /Site/root/.router.php
  • /BlackFox/root/.router.php
    		•

    Следуя этой логике, вы можете переопределить любой файл в виртуальном корне фреймворка, создав в своём виртуальном корне файл по аналогичному относительному пути.

    Если ни один файл не найден, Engine ищет редирект или контент из базы данных (сущности Redirects и Pages),
    а если и там ничего не найдено — бросает исключение ExceptionPageNotFound, которое в последующем обрабатывается в методе Show404.

    Это поведение движка можно изменить, изучив и переопределив метод MakeContent.

    Доступ к разделам (папкам)

    Engine позволяет для каждого раздела переопределять подключаемый шаблон и/или обёртку шаблона, а также ограничить/разрешить доступ к разделу и всем подразделам для конкретных групп пользователей. Для этого нужно создать файл .section.php в корне раздела и вернуть в нём ассоциативный массив, описывающий раздел (все ключи не обязательны):

    • TEMPLATE — код шаблона
    • WRAPPER — код обёртки шаблона
    • ACCESS — ассоциативный массив, описывающий доступ к разделу: ключ - код группы пользователей, значение - true/false флаг доступа

    Например

    <?php return [ 'TEMPLATE' => 'admin', 'ACCESS' => [ '*' => false, 'root' => true, ], ];
    • * — псевдо-код для любого пользователя (в том числе не авторизованного)
    • @ — псевдо-код для авторизованного пользователя
    • root — код группы пользователей "Рут"

    Для более сложной логики ограничения доступа используйте исключения в собственном коде.

    Шаблон

    По завершении обработки запроса, Engine оборачивает результат в обёртку шаблона, если это необходимо.
