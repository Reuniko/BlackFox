Шаблон и обёртка

Шаблон — это папка с php-файлами, некоторые из которых используются как обёртки для генерации страницы.
Обёртка — это php-файл, содержащий шапку (хидер) + вызов контента страницы + подвал (футер).
Название папки является кодом шаблона (например: bootstrap).
Название php-файла без расширения является кодом обёртки шаблона (по умолчанию: wrapper).
Один шаблон может содержать множество обёрток.
Помимо исполняемых файлов шаблон может содержать прочие статичные файлы для подключения (скрипты, стили и изображения).

Обёртка шаблона должна содержать вызов на печать названия страницы, заголовков и контента:

<?php /** @var \BlackFox\Engine $this */ ?> <!DOCTYPE html> <html> <head> <?= $this->GetHeader() ?> <title><?= $this->TITLE ?></title> </head> <body> <h1><?= $this->TITLE ?></h1> <?= $this->CONTENT ?> </body> </html>
$CONTENT
контент страницы, генерируется в подключаемом файле, находящемся в виртуальном корне
$TITLE
название страницы
$TEMPLATE_PATH
путь к папке шаблона относительно корня сервера
GetHeader()
динамически подключаемые скрипты и стили

Скрипты и стили, присутствующие на всех страницах, можно подключить обычным способом.
Если в процессе генерации контента страницы понадобилось подключить дополнительные скрипты и стили, воспользуйтесь методами AddHeaderScript, AddHeaderStyle, AddHeaderString:

<?php /** @var \BlackFox\Engine $this */ $this->AddHeaderScript($this->TEMPLATE_PATH . '/script.js'); $this->AddHeaderStyle($this->TEMPLATE_PATH . '/style.css'); $this->AddHeaderString('<meta .../>');

Управление шаблоном и обёрткой

Есть возможность динамически переопределять код шаблона и код обёртки.

Для всего раздела в файле .section.php: return [ 'TEMPLATE' => 'another_template', 'WRAPPER' => 'another_wrapper', ];
Для конкретного исполняемого файла: /** @var \BlackFox\Engine $this */ $this->TEMPLATE = 'another_template'; $this->WRAPPER = 'another_wrapper';

Обработка ошибок при генерации страницы

Находящийся в корне шаблона файл errors.php не является обёрткой, используется движком для генерации контента страницы, отображающего ошибки, возникшие при генерации оригинальной страницы.

<?php /** @var \BlackFox\Engine $this */ ?> <?php /** @var array $errors */ ?> <?php foreach ($errors as $error): ?> <div class="alert alert-danger"><?= $error ?></div> <?php endforeach; ?>

При желании это поведение движка можно переопределить, переопределив метод ShowErrors класса Engine.
