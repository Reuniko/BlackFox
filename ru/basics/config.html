Конфигурирование

Файл /config.php должен вернуть конфигурационный массив. Вы можете добавлять в него свои ключи и использовать их.

Пример

return [ 'debug' => true, 'cores' => [ 'Site' => $_SERVER['DOCUMENT_ROOT'] . '/Site', 'BlackFox' => $_SERVER['DOCUMENT_ROOT'] . '/BlackFox', ], 'roots' => [ '/Site/root' => $_SERVER['DOCUMENT_ROOT'] . '/Site/root', '/BlackFox/root' => $_SERVER['DOCUMENT_ROOT'] . '/BlackFox/root', ], 'languages' => [ 'en' => 'English', 'ru' => 'Русский', ], 'templates' => [ 'main' => '/Site/templates/main', 'admin' => '/BlackFox/templates/admin', ], 'overrides' => [ 'BlackFox\Engine' => 'Site\Engine', 'BlackFox\Database' => 'BlackFox\MySQL', ], 'database' => [ 'HOST' => 'localhost', 'PORT' => 3306, 'USER' => 'root', 'PASSWORD' => '', 'DATABASE' => 'site', ], ];
  • /Site — папка с вашим ядром
  • /BlackFox — папка с фреймворком (которое тоже является ядром)

Расшифровка ключей

debug
bool, установка параметра в true позволяет глобальной функции debug() работать
cores
словарь ядер:
  • key - неймспейс ядра
  • value - абсолютный путь к папке с ядром
    • первый ключ обладает высшим приоритетом
    roots
    словарь корней:
  • key - относительный путь к папке с корнем
  • value - абсолютный путь к папке с корнем
    • первый ключ обладает высшим приоритетом
    languages
    словарь используемых языков (может быть пустым):
  • key - символьный код языка
  • value - название языка
    • первый ключ является языком по умолчанию
    templates
    словарь доступных шаблонов:
  • key - код шаблона
  • value - относительный путь к папке шаблона
    • overrides
    словарь, описывает переопределение классов:
  • key - переопределяемый класс
  • value - переопределяющий класс
    • для совместимости рекомендуется переопределять классы их наследниками
    database
    словарь реквизитов для подключения к базе данных по умолчанию, ключи зависят от драйвера
